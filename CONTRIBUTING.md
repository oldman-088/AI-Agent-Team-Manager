# Contributing

Use a virtual environment for future dependencies; no packages are needed for the current prototype. Run `python -m unittest discover -s tests -v`, `python -m compileall -q team_manager tests`, and `python scripts/check_docs.py` before submitting. Use descriptive commits and review changes through a pull request. Never commit credentials, browser profiles, or local data. Describe testing, limitations and security impact. Feature branches are recommended outside environments that constrain branch selection.
